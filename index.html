How to Deploy on Vercel

  2. Go to GitHub.com, create a public repository (e.g., hicu222-homework).
  3. Upload your index.html file to the repository.
  4. Go to Vercel.com, sign in with GitHub, and click **Add New > Project**.
  5. Import your repository and click **Deploy** to get your permanent public URL (.vercel.app)!
